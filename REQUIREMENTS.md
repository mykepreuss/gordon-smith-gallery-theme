# Requirements register

One row per requirement in `IMPLEMENTATION_PLAN.md`. The **source wording** is quoted from the developer notes (`reference/Gordon Smith Gallery Website Notes for Developer.docx.md`), the authoritative requirements. Update a row in the same commit as the work it describes.

- **Status:** Not started, In progress, In review, Blocked (name the dependency), Done. Done needs both storefront and staff-editing evidence (plan, "Verification and completion rules"). Read-only discovery and design work are not completion evidence, so every row starts Not started.
- **Surface:** `theme` (Liquid, CSS, JS, templates, theme settings), `store` (menus, pages, fields, products, collections, Files, redirects), `editorial` (words and labels from the gallery), `mixed`.
- **Owner:** Dev = implementation (Michael). Gallery = staff input or approval.
- **Baseline evidence** points into `baseline/`. **Design** points into `design-system/DESIGN.md`.
